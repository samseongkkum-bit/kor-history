# 한옥 마당 한국사 퀴즈 (여러 명 동시 접속)

초·중학생 체험 부스에서 쓰는 한국사 퀴즈 게임입니다.
학생들이 **각자 자기 폰·태블릿으로 같은 한옥 마당에 들어와**, 자기 캐릭터를 움직여
정답 자리(돗자리)에 서면 함께 채점받습니다.

- **진행자 화면** — 부스의 큰 모니터·노트북에 띄웁니다. 입장 코드와 QR, 학생 명단, 문제와 순위를 보여 줍니다.
- **학생 화면** — 학생들의 폰·태블릿. 코드를 넣고 들어와 캐릭터를 움직입니다.
- **혼자 하기** — 네트워크가 안 될 때 쓰는 1인용 비상 버전입니다.

---

## 1. 설치 (처음 한 번만)

### 1-1. Node.js 설치

컴퓨터에 **Node.js 20 이상**이 필요합니다. 설치되어 있는지는 터미널(맥은 *터미널*, 윈도우는 *PowerShell*)에서 확인합니다.

```bash
node -v
```

`v20.0.0`처럼 숫자가 나오면 됩니다. 아무것도 안 나오거나 숫자가 20보다 작으면
<https://nodejs.org> 에서 **LTS** 버전을 내려받아 설치한 뒤 터미널을 새로 여세요.

### 1-2. 이 폴더에서 설치 명령 실행

터미널에서 이 폴더로 이동한 뒤 아래를 한 번 실행합니다. (인터넷이 필요합니다. **부스 가기 전에 미리 해 두세요.**)

```bash
npm install
```

몇 분 걸립니다. 끝나면 `node_modules` 폴더가 생깁니다. 다음부터는 다시 할 필요 없습니다.

> **부스에 인터넷이 없어도 괜찮습니다.** 필요한 프로그램은 모두 이 폴더 안에 들어오고,
> 서버가 직접 보내 줍니다. 글꼴만 인터넷이 있으면 더 예쁘게 나오고, 없으면 비슷한
> 글꼴로 자연스럽게 바뀝니다.

## 2. 실행 (부스에서 매번)

```bash
npm start
```

이런 화면이 나옵니다.

```
────────────────────────────────────────────────────
  한국사 퀴즈 서버가 켜졌어요!
────────────────────────────────────────────────────
  진행자 화면 (부스 노트북)   http://localhost:3000/host
  학생 화면   (학생 기기)     http://192.168.0.111:3000/play
  혼자 하기   (비상용)        http://localhost:3000/solo
────────────────────────────────────────────────────
  끄려면 이 창에서 Ctrl + C 를 누르세요.
```

여기 나오는 **`192.168.0.111` 같은 숫자가 부스 노트북의 주소**입니다.
학생 기기가 이 주소로 들어옵니다. (숫자는 장소마다 다릅니다.)

### 중요: 같은 와이파이에 붙어야 합니다

노트북과 학생 기기가 **같은 와이파이**에 붙어 있어야 합니다.
학교 와이파이를 쓸 수 없으면 **노트북이나 휴대폰의 핫스팟**을 켜고 모두 거기에 붙이면 됩니다.

> 학교 와이파이 중에는 기기끼리 서로 통신하지 못하게 막아 둔 곳이 있습니다
> (보통 "AP 격리", "게스트 네트워크"). 이때는 학생 기기가 들어오지 못하니
> **핫스팟을 쓰세요.** 미리 한 번 시험해 보는 것을 권합니다.

이 창은 부스가 끝날 때까지 **닫지 마세요.** 창을 닫으면 서버가 꺼집니다.

## 3. 진행자 화면 열기

1. 노트북 브라우저에서 **<http://localhost:3000/host>** 를 엽니다.
2. **[방 만들기]** 를 누릅니다.
3. **4자리 입장 코드**와 **QR 코드**가 크게 나옵니다. 학생들에게 이 화면을 보여 주세요.

![진행자 화면 구성]
- 왼쪽: 한옥 마당(학생 캐릭터들이 돌아다니는 곳)
- 오른쪽 위: 입장 코드와 QR
- 오른쪽: 단계 고르기 / 시작·다음 문제·강제 종료 / 순위 / 학생 명단
- 오른쪽 맨 위 구석: **오늘 참여 인원 합계**

## 4. 학생 입장

학생은 둘 중 아무 방법이나 쓰면 됩니다.

- **QR 코드 찍기** — 폰 카메라로 진행자 화면의 QR을 찍으면 코드까지 자동으로 들어갑니다. (가장 쉽습니다)
- **주소 직접 넣기** — 브라우저에 `http://192.168.0.111:3000/play` 를 치고, 4자리 코드를 넣습니다.

학생 화면에서 할 일:
1. **입장 코드** 4자리 (QR로 들어오면 이미 채워져 있습니다)
2. **이름** (최대 8글자, **별명도 괜찮다고 안내해 주세요**)
3. **저고리 색** 고르기
4. **[마당에 들어가기]**

> **개인정보는 받지 않습니다.** 이름 칸에 별명을 써도 됩니다.
> 서버에 남는 기록에는 이름이 들어가지 않고 인원 수와 점수만 남습니다.
>
> 같은 방에 같은 이름이 있으면 자동으로 뒤에 숫자가 붙습니다(`민수`, `민수2`).
> 장난스러운 이름을 쓴 학생은 진행자 화면 명단의 **[내보내기]** 로 내보낼 수 있습니다.

**한 방에 최대 30명**까지 들어옵니다. 더 많으면 방을 하나 더 만들어 나눠 받으세요(여러 방을 동시에 열 수 있습니다).

## 5. 게임 진행

### 진행 순서

1. 학생들이 다 들어오면 진행자 화면에서 **단계**를 고릅니다.
   - **초등부** — O/X 30문제 중 10문제
   - **중등부** — 객관식 15 + O/X 15, 총 30문제 중 10문제
2. **[게임 시작]** 을 누릅니다.
3. 문제가 나오면 학생들이 각자 캐릭터를 움직여 정답 자리에 섭니다.
   - **제한 시간**: O/X 12초, 객관식 20초
   - 시간이 끝나면 **그때 서 있던 자리**로 채점합니다.
   - 미리 정하고 싶으면 **[여기로 결정!]** 을 누릅니다. 빨리 정할수록 동점일 때 순위가 앞섭니다.
4. 시간이 끝나면 **정답 공개 → 해설 → 그때까지의 순위(상위 5명)** 가 나옵니다.
5. 진행자가 **[다음 문제]** 를 누르면 다음 문제로 넘어갑니다. (설명할 시간을 충분히 가지세요.)
6. 10문제를 다 풀면 **최종 순위와 각자의 칭호**가 나옵니다.

### 학생 조작법

- 방향키 또는 **W A S D**
- **마당을 손가락으로 누르면** 그쪽으로 걸어갑니다 (폰·태블릿에서 가장 편합니다)
- 화면 아래 **방향 버튼** (태블릿용)
- 모르겠으면 마당 구석의 **두루마리**로 가거나 **[힌트 보기]** 를 누릅니다. **힌트는 그 학생에게만 보입니다.**

### 칭호 (10점 만점)

| 점수 | 칭호 | 점수 | 칭호 |
|---|---|---|---|
| 0–2점 | 천민 | 7–8점 | 귀족 |
| 3–4점 | 양민 | 9점 | 조선의 학자 |
| 5–6점 | 평민 | 10점 | 왕 |

### 이럴 때는 이렇게

| 상황 | 어떻게 되나요 |
|---|---|
| 학생이 새로고침했어요 | **같은 기기면 이름과 점수가 그대로 이어집니다.** 자동으로 다시 들어갑니다. |
| 와이파이가 잠깐 끊겼어요 | 다시 붙으면 저절로 이어집니다. 그동안의 점수는 남아 있습니다. |
| 진행자 화면을 새로고침했어요 | **방은 사라지지 않습니다.** 같은 방으로 다시 들어갑니다. |
| 학생이 게임 중간에 들어왔어요 | **다음 문제부터** 함께 풉니다. (지금 문제는 구경만 합니다) |
| 시간이 모자라요 | **[강제 종료]** 를 누르면 그때까지의 점수로 최종 순위가 나옵니다. |
| 한 판 더 하고 싶어요 | 최종 결과에서 **[새 문제로 한 판 더]** 를 누르세요. **30문제를 한 바퀴 다 돌 때까지 같은 문제가 다시 나오지 않습니다.** |
| 다음 조가 왔어요 | 그냥 **[새 문제로 한 판 더]** 를 눌러도 되고, 학생들에게 새로 들어오라고 해도 됩니다. |

## 6. 부스가 끝난 뒤: 참여 인원 기록

게임이 한 판 끝날 때마다 `data/participation.jsonl` 파일에 한 줄씩 쌓입니다.

```
{"date":"2026-10-05","time":"14:30","level":"elem","levelName":"초등부","players":12,"questions":10,"avgScore":6.4}
```

| 항목 | 뜻 |
|---|---|
| `date` / `time` | 날짜와 시각 |
| `levelName` | 단계 (초등부 / 중등부) |
| `players` | 그 판에 참여한 인원 |
| `questions` | 그 판에서 푼 문제 수 |
| `avgScore` | 평균 점수 |

**학생 이름은 남지 않습니다.** 보고서를 쓸 때 이 파일을 엑셀로 열거나
진행자 화면 오른쪽 위의 **"오늘 참여 인원 합계"** 숫자를 그대로 쓰면 됩니다.

기록을 처음부터 새로 시작하려면 이 파일을 **지우면** 됩니다(다음 게임이 끝나면 새로 생깁니다).
`npm run test:e2e` 로 시험 삼아 돌려 본 기록이 섞였을 때도 지우고 시작하세요.

> 이 파일은 서버를 꺼도 지워지지 않습니다. 다른 기록은 모두 메모리에만 있어서
> 서버를 끄면 사라집니다(데이터베이스를 쓰지 않습니다).
>
> **단, 인터넷에 올려서 쓴 경우(8번)에는 다시 배포하거나 서버가 잠들면 이 파일이 사라집니다.**
> 부스가 끝나면 그날 안에 내려받아 두세요. 부스 노트북에서 `npm start` 로 쓴 기록은 그대로 남습니다.

## 7. 문제 고치기 (`data/questions.json`)

문제는 모두 **`data/questions.json`** 한 파일에 들어 있습니다.
메모장이나 "텍스트 편집기"로 열어서 고치면 됩니다.

### 파일 생김새

```json
{
  "elem": {
    "name": "초등부",
    "kind": "O/X 퀴즈",
    "desc": "태극기, 한글, 명절처럼 생활 속에서 만나는 우리 역사",
    "questions": [
      {
        "t": "ox",
        "q": "우리나라 국기의 이름은 '태극기'이다.",
        "a": "O",
        "hint": "가운데에 빨간색과 파란색 동그라미가 있어요.",
        "ex": "태극기는 가운데 태극 무늬와 네 귀퉁이의 검은 막대(4괘)로 이루어져 있어요."
      }
    ]
  }
}
```

### 항목 설명

| 이름 | 뜻 |
|---|---|
| `t` | 문제 종류. `"ox"` 는 O/X, `"mc"` 는 객관식 |
| `q` | 문제 문장 |
| `a` | 정답. O/X는 `"O"` 또는 `"X"`, 객관식은 **몇 번째 보기인지 0부터 센 숫자** |
| `c` | 객관식일 때만. 보기 **4개**를 순서대로 |
| `hint` | 힌트 한 줄 |
| `ex` | 해설 한 줄 |

### 객관식 예시

```json
{
  "t": "mc",
  "q": "우리 역사에서 처음 세워진 나라는?",
  "c": ["고구려", "고조선", "신라", "가야"],
  "a": 1,
  "hint": "단군 이야기와 관련 있어요.",
  "ex": "고조선은 단군왕검이 세운 우리 역사 최초의 국가예요."
}
```

> `"a": 1` 은 **두 번째** 보기인 `"고조선"` 이 정답이라는 뜻입니다.
> 0 = 첫 번째, 1 = 두 번째, 2 = 세 번째, 3 = 네 번째.
> 보기 순서는 게임마다 자동으로 섞이지만 정답은 따라다니므로 걱정하지 않아도 됩니다.

### 고칠 때 주의할 점

- 큰따옴표 `"` 와 쉼표 `,` 를 빠뜨리지 마세요. 하나만 틀려도 서버가 켜지지 않습니다.
- 문제 안에 큰따옴표를 쓰려면 `\"` 처럼 앞에 `\` 를 붙입니다.
- **문제 수는 단계마다 30문제를 권합니다.** 한 판에 10문제씩 뽑으므로 30문제면 세 판 동안 겹치지 않습니다.
- 고친 뒤에는 **서버를 껐다가(Ctrl + C) 다시 켜야(`npm start`)** 반영됩니다.
- 고치기 전에 파일을 복사해 두면 안전합니다.

### 제대로 고쳤는지 확인하기

```bash
npm test
```

문제 데이터와 출제·채점 로직을 검사합니다. 초록색 `pass` 가 나오면 괜찮습니다.

## 8. 인터넷에 올리기 (선택)

부스 현장에서는 **위의 `npm start` 만으로 충분합니다.**
멀리 있는 학생도 참여하게 하려면 무료 서비스에 올릴 수 있습니다.

### Render (무료)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. <https://render.com> 에 가입하고 **New → Web Service** 에서 그 저장소를 고릅니다.
3. 이 폴더의 `render.yaml` 을 알아서 읽습니다. 그대로 **Create** 합니다.
4. 배포가 끝나면 `https://○○○.onrender.com` 같은 주소가 나옵니다.
5. **중요**: Render 대시보드의 **Environment** 에서 환경 변수를 추가합니다.
   - 이름 `PUBLIC_URL`, 값 `https://○○○.onrender.com` (4번에서 받은 주소, 끝에 `/` 없이)
   - 저장하면 다시 배포됩니다. 이제 진행자 화면의 **QR이 이 주소를 가리킵니다.**
6. 진행자는 `https://○○○.onrender.com/host`, 학생은 `https://○○○.onrender.com/play` 로 들어갑니다.

> 무료 플랜은 15분 동안 아무도 안 들어오면 잠듭니다.
> 부스를 시작하기 **10분 전에 진행자 화면을 미리 열어 두세요.** 처음 한 번만 30초쯤 걸립니다.

### Railway (무료 체험)

1. GitHub 저장소를 올립니다.
2. <https://railway.app> 에서 **New Project → Deploy from GitHub repo** 로 고릅니다.
3. `railway.json` 을 알아서 읽습니다.
4. **Variables** 에 `PUBLIC_URL` 을 추가하고 값으로 배포 주소를 적습니다(끝에 `/` 없이).
5. **Settings → Networking → Generate Domain** 으로 주소를 만듭니다.

`PUBLIC_URL` 을 적지 않아도 대부분 알아서 맞는 주소를 씁니다. 다만 QR이 이상한 주소를 가리키면 꼭 적어 주세요.

## 9. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| `npm start` 했는데 `command not found: npm` | Node.js가 설치되지 않았습니다. 1-1로 돌아가세요. |
| `Error: Cannot find module` | `npm install` 을 안 했습니다. 1-2를 하세요. |
| `EADDRINUSE` (주소가 이미 쓰이는 중) | 서버가 이미 켜져 있습니다. 기존 창에서 Ctrl + C 로 끄고 다시 켜세요. 또는 `PORT=3001 npm start` 로 다른 번호를 쓰세요. |
| 학생 기기에서 주소를 넣어도 안 열림 | ① 같은 와이파이인지 ② 주소의 숫자가 맞는지 ③ 와이파이가 기기끼리 막고 있지는 않은지(핫스팟을 쓰세요) |
| 글꼴이 평소와 달라 보임 | 인터넷이 없어서 대체 글꼴로 나온 것입니다. 글자는 그대로 잘 읽힙니다. |
| 캐릭터가 뚝뚝 끊겨 움직임 | 와이파이가 약합니다. 노트북과 학생들이 공유기에 가까이 가세요. |
| `문제 파일(data/questions.json)에 잘못된 곳이 있어요` | 서버가 **몇째 줄이 잘못됐는지** 알려 줍니다. 그 줄의 쉼표·따옴표를 고치고 다시 켜세요. 7번도 보세요. |
| 인터넷이 아예 안 돼요 | **<http://localhost:3000/solo>** 로 한 명씩 돌아가며 하면 됩니다. |

### 소켓 이벤트

| 방향 | 이벤트 | 내용 |
|---|---|---|
| 진행자→서버 | `host:create` `host:resume` `host:setLevel` `host:start` `host:next` `host:endGame` `host:kick` | 방 만들기·이어받기·단계·진행·내보내기 |
| 학생→서버 | `play:join` `play:move` `play:lock` `play:hint` | 입장·위치(12Hz)·자리 확정·힌트(본인만) |
| 서버→방 | `room:state` `room:positions`(10Hz) `room:question` `room:zoneCounts` `room:reveal` `room:final` `room:closed` | 문제에는 정답·해설·힌트를 담지 않음 |
| 서버→학생 | `play:result` `play:kicked` | 본인 채점 결과 |

### 설계상 정해 둔 것

- **채점과 시간은 서버가 결정합니다.** 서버가 `startAt`/`endAt`을 보내면 클라이언트는 남은 시간을 그리기만 합니다. 마감 순간 서버가 알고 있는 마지막 위치로 채점합니다.
- 서버는 위치가 마당 밖으로 나가지 못하게 막고, 걷는 속도(260px/초)보다 빠른 이동은 그 속도까지만 인정합니다.
- 점수는 **정답 1점**뿐입니다(칭호는 이 10점 만점 기준). **빠르기 보너스**는 따로 계산해 순위표의 동점 처리에만 씁니다.
- 방은 메모리에만 있고, 아무도 없는 방은 **15분 뒤** 정리됩니다.
